1. EAF Browser

EAF (Emacs Application Framework) is a framework that extends Emacs with modern graphical capabilities by embedding a Qt6 WebEngine view. EAF Browser is the web browser application built on it — a full-featured, keyboard-driven browser that runs inside Emacs.

2. Install

2.1. System Dependencies (macOS)

EAF depends on Qt6 WebEngine and Python. Install them via brew:

brew install python@3.13 qt6 pyqt6

Use Python 3.13 (the recommended version). Make sure python3 points to the brew-installed one:

which python3
# should output /opt/homebrew/bin/python3

2.2. Install aria2 (optional, for downloads)

brew install aria2

2.3. Install pycookiecheat (optional, for Chrome cookie import)

pip3 install pycookiecheat

2.4. Install EAF Framework + Browser

Neo-emacs uses doom’s straight.el to install both eaf and eaf-browser from source. The package recipes are in packages.el:

(package! eaf
  :recipe (:host github
           :repo "emacs-eaf/emacs-application-framework"
           :branch "master"
           :files ("*.el" "*.json" "*.py" "core" "app")))

(package! eaf-browser
  :recipe (:host github
           :repo "emacs-eaf/eaf-browser"
           :branch "master"
           :files (:defaults "*.py" "dependencies.json" "easylist.txt" "aria2-ng" "node_modules")))

After the packages are pulled, run the EAF installer to set up Python dependencies:

cd ~/.emacs.d/.local/straight/repos/emacs-application-framework/
python3 install-eaf.py

Or use M-x eaf-install-and-update inside Emacs.

2.5. Verify Installation

Open EAF’s demo to check everything works:

M-x eaf-open-demo

If the demo window appears, EAF is installed correctly.

3. Configuration

Neo-emacs configures EAF Browser in config.el with sensible defaults:

3.1. Core Settings

(setq eaf-python-command "/opt/homebrew/bin/python3"
      eaf-browser-continue-where-left-off t
      eaf-browser-enable-adblocker t
      eaf-proxy-type "http"
      eaf-proxy-host "127.0.0.1"
      eaf-proxy-port "10887"
      eaf-start-python-process-when-require nil)

3.2. Proxy & Chromium Flags

QtWebEngine runs Chromium under the hood. Neo-emacs configures proxy and flags via environment variables:

(setenv "QTWEBENGINE_CHROMIUM_FLAGS"
        "--no-sandbox --disable-features=WebRtcHideLocalIpsWithMdns
         --enable-features=PlatformHEVCDecoderSupport
         --enable-gpu-rasterization --ignore-gpu-blocklist
         --proxy-server=http://127.0.0.1:10887
         --user-agent=\"Mozilla/5.0 ...\"")
(setenv "QTWEBENGINE_DISABLE_SANDBOX" "1")

Proxy auto-toggle is handled by an advice:

(defun my/eaf-enable-proxy (&rest _)
  (ignore-errors
    (when (and (boundp 'eaf-proxy-type) eaf-proxy-type eaf-epc-process)
      (eaf-call-async "toggle_proxy"))))
(advice-add 'eaf-open-browser :after #'my/eaf-enable-proxy)

3.3. Browser Defaults

(setq browse-url-browser-function 'eaf-open-browser)
(defalias 'browse-web #'eaf-open-browser)
(require 'eaf-browser)
(eaf-setq eaf-browser-default-search-engine "google")

(setq eaf-browser-auto-import-chrome-cookies t
      eaf-browser-enable-adblocker t
      eaf-browser-enable-autofill t
      eaf-browser-dark-mode "ignore"
      eaf-chrome-bookmark-file "~/Desktop/bookmarks_2026_8_17.html"
      eaf-browser-default-zoom 1.0
      eaf-browser-enable-javascript t
      eaf-browser-enable-aria2 t
      eaf-browser-aria2-download-dir "~/Downloads/"
      eaf-browser-history-file (concat doom-data-dir "eaf/browser/history.log")
      eaf-browser-bookmark-file (concat doom-data-dir "eaf/browser/bookmarks.log")
      eaf-browser-cookie-file (concat doom-data-dir "eaf/browser/cookies"))

4. Usage

4.1. Launch Commands

Command Description
M-x eaf-open-browser Open browser (search or URL)
M-x eaf-open-browser-with-history Open browser with history selection
M-x eaf-open-bookmark Open bookmark manager
M-x eaf-open Open file in appropriate EAF app

4.2. Key Bindings (SPC Leader)

Key Command Description
SPC o b eaf-open-browser Open EAF browser
SPC o B eaf-open-browser-with-history Open with history
SPC o e eaf-open Open file in EAF
C-c b eaf-open-bookmark Open bookmarks

4.3. EAF Browser Mode Key Bindings

EAF Browser has two modes: insert mode (normal browsing) and input mode (for text input in web forms).

  1. Navigation
    Key Event
    C-n scroll_up
    C-p scroll_down
    C-f scroll_right
    C-b scroll_left
    C-v scroll_up_page
    M-v scroll_down_page
    M-f history_forward
    M-b history_backward
    M-t new_blank_page
  2. Zoom
    Key Event
    C-- zoom_out
    C-= zoom_in
    C-0 zoom_reset
  3. Text / Clipboard
    Key Event
    C-w kill_text
    C-y yank_text
    M-w copy_text
    M-e atomic_edit
  4. Neo-Emacs Custom Bindings
    Key Command Description
    J +workspace/switch-left Switch workspace left
    K +workspace/switch-right Switch workspace right
    B consult-buffer Switch buffer
    R eaf-restart-process Restart EAF process
    Q eaf-safe-close-buffer Safely close buffer
    M-[ history_backward Go back
    M-] history_forward Go forward
    M-y eaf-consult-yank-pop Paste from kill-ring
    M-i switch_to_input_mode Toggle input mode
  5. Input Mode Toggle

    When a web page requires text input, press M-i to switch to input mode. On macOS, this also activates the EAF window via AppleScript for proper IME support.

4.4. Chrome Cookie Import

When eaf-browser-auto-import-chrome-cookies is set to t, EAF Browser automatically imports cookies from Chrome on startup. You don’t need to log in separately.

Supported Chrome-based browsers: Chrome (default), Chromium, Brave. Set via eaf-browser-chrome-browser-name.

5. Troubleshooting

5.1. EAF doesn’t start

  • Check eaf-python-command points to the correct Python 3.13
  • Run M-x eaf-install-and-update to install missing Python deps
  • Check the *eaf* buffer for error messages

5.2. Sandbox issues on macOS

EAF disables sandboxing by default (QTWEBENGINE_DISABLE_SANDBOX=1) because QtWebEngine sandboxing conflicts with some macOS configurations.

5.3. Proxy not working

Ensure your proxy settings are correct in config.el. The proxy is toggled automatically when opening a browser, but verify with eaf-proxy-type, eaf-proxy-host, and eaf-proxy-port.

5.4. Update EAF

cd ~/.emacs.d/.local/straight/repos/emacs-application-framework/
git pull
python3 install-eaf.py

Then run doom sync in Emacs to rebuild.
